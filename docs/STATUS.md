# Project Status

This page tracks API coverage of the pinned upstream `gpui-kit` crates and the results of the automated verification gates. Everything inside the two generated blocks below is produced by scripts and should never be edited by hand.

## Coverage Categories

`gen/gkgen.py` classifies every public function in the pinned upstream extract (`api/rustdoc/*.json.gz`) into `api/coverage.json`, and `tools/status.py` (`make status`) renders the table below:

| Status | Meaning |
|---|---|
| `bound` | Generated by rule directly onto the tape protocol and accepted by both compilers. |
| `bridged` | Generated against a hand-written runtime protocol (handlers, states, row sources, overlays, plots, motion, platform services, or shims). |
| `skipped` | Intentionally excluded under one of the 12 fixed `SKIP_REASONS` in `gen/gk_model.py` (such as `platform-trait`, `test-only`, `third-party-type`, `hidden`, `feature-off`, `rust-only-extension`, `item-render-closure`, `builder-getter`, `builder-mutator`, `value-helper`, `deprecated`, `unsafe`). |
| `failed` | Generated and rejected by a compiler (`api/quarantine.json`). |
| `not yet` | Not matched by any current generator rule (`todo`). |
| `verified` | Exercised by a passing byte-identical gallery page (`gates/verified.json`). |

Every row satisfies `total = bound + bridged + skipped + failed + not yet`, with `verified <= bound + bridged`. Style tokens (nullary `Styled` methods generated by a single rule) are reported separately so they do not skew the real-function headline.
